# Cinelog

Film ve dizi takip platformu. Monorepo olarak yapılandırılmıştır.

## Yapı

```
apps/
  movie_tracker/   Flutter uygulaması (TMDb API, Hive yerel depolama)
```

Backend ve veritabanı eklendiğinde `apps/` altına ayrı bir klasör (ör. `apps/backend`) olarak eklenecektir.

Her uygulamanın kendi README'si kendi klasöründe bulunur.
